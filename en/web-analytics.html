The audit tool events carry parameters (tested domain, contact channel). I registered them as custom dimensions in GA4, which makes it possible to see each step of the audit site by site.

My method

  1. Define what counts as a conversion, with the person who uses the numbers.
  2. Set up the tags in Google Tag Manager, with precise triggers and readable event names.
  3. Check every tag in GTM preview mode before publishing a version.
  4. Register the useful parameters as custom dimensions in GA4.
  5. Build the dashboard in Data Studio, connected to GA4 and Search Console.
